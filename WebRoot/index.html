- it finally works -

This page is served directly from my Java HTTP server!!! Although it's a very simple server, it does have the basic features required by rfc that makes it fully functional.

1. GET Request

The browser asks the server for this page.

2. HttpParser

Then it reads the request and finds what to serve.

3. WebRootHandler

Then it finds files in the WebRoot folder.

4. Response

Then finally, the server sends the page back to the browser.
